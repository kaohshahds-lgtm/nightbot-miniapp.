NIGHTBOT — Mini App с твоими двумя баннерами

Загрузка на GitHub:
1. Распакуй архив.
2. В GitHub создай Public repository nightbot-miniapp.
3. Загрузи index.html и папку assets целиком (в ней welcome.jpg и scripts.jpg).
4. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. Открой выданный HTTPS адрес.

Подключение:
@BotFather -> /mybots -> выбери бота -> Bot Settings -> Menu Button -> Configure menu button.
Укажи HTTPS адрес GitHub Pages.

ВАЖНО:
Это интерфейс Mini App. Чтобы администратор мог менять баннеры/скрипты прямо из Telegram и изменения сохранялись у всех пользователей, нужна серверная часть и защищённые admin API. Не публикуй токен бота в HTML/GitHub.
